~/research

M.S. thesis, Cyber-Physical Systems Security Lab, UT Arlington, 2026.

Do vulnerability detectors survive obfuscation?

Thesis Evaluating the Robustness of GNN Vulnerability Detectors Under Code Obfuscation

Graph neural networks can look very good at spotting vulnerable code on clean benchmarks. Real code is messier, and sometimes deliberately disguised. My thesis evaluates how these detectors behave when code is transformed in ways that keep its behaviour identical: renamed identifiers, dead branches, reshaped control flow.

GraphSentinel is the service I built to flag these transformations automatically, so experiments can run over whole datasets.
